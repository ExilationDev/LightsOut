# Lights Out
You find yourself in a strange cave. you must keep your torch lit for if it dies so will you. you dive deeper into the abyss finding treasure, getting stronger and keeping yourself alive.

## Description
Lights Out is a roguelike dungeon crawler game created by the `3Ds` for a school project. It consists of randomly generated dungeons (caves in this game) with rooms and layouts that can either ruin or benefit your run.
