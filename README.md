# Lights Out
You stand with your torch in hand in a strange place with mazes. You, the player, have no clue where the exit is. Your objective is to navigate and escape this wretched maze while trying to escape its layered floors.

## Description
Lights Out is a roguelike dungeon crawler game created by the `3Ds` for a school project. It consists of randomly generated dungeons (caves in this game) with rooms and layouts that can either ruin or benefit your run.
